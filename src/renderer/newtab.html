Aa Browser

为 AI Agent 而生的浏览器

人像人一样浏览网页，Agent 像工程师一样驱动它。
  1. 正常使用：这是一个完整的 Chromium 浏览器，地址栏、标签页、登录态都和普通浏览器一样。
  2. 接入 Agent：在你的 AI 编程助手（ZCode / Claude Code / Cursor 等）的 MCP 配置中添加 aa-browser-mcp。
  3. 开始协作：Agent 将通过结构化页面快照（可访问性树 + 元素 ref）阅读网页、点击、输入、提取数据。
// 在 Agent 的 mcp 配置中添加： { "mcpServers": { "aa-browser": { "command": "node", "args": ["<本仓库路径>/cli/mcp.mjs"] } } }
快捷键：Ctrl+T 新标签页 · Ctrl+W 关闭 · Ctrl+L 聚焦地址栏 · F5 刷新
