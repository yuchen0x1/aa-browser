Aa Browser · 本地 Agent 浏览器
Aa Browser

浏览器为人操作，也为 Agent 提供清晰反馈。

在熟悉的 Chromium 标签页中浏览；需要时，让 AI 读取页面结构并执行可检查的操作。

连接 AI 客户端

在工具栏「设置」里勾选客户端即可写入 MCP 配置：写入前自动备份，只改 aa-browser 一个键。
写入成功不等于客户端已加载工具；请在客户端内确认工具清单后调用一次 browser_tabs 验证。
浏览
熟悉的标签式浏览
地址栏、浏览历史和独立标签页会话都在同一个桌面窗口中。
控制
页面结构与操作
Agent 可读取结构化页面快照，再按元素引用执行操作并查看结果。
检查
页面与网络诊断
查看请求、控制台和下载记录；认证信息在诊断输出中默认遮蔽。
mcp-config.json — 手动配置
// 传统 MCP 客户端配置（与一键接入等效）： { "mcpServers": { "aa-browser": { "command": "node", "args": ["<安装目录>/cli/mcp.mjs"] } } }
