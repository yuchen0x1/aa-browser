# v0.15.0 recovery slice

This workspace contains a focused, verifiable part of the requested upgrade.

## Implemented

- `TabManager` now exposes optional recovery metadata for every tab.
- Electron `render-process-gone` and `unresponsive` events enter a bounded recovery state.
- Recovery reloads the existing WebContents at most twice, preserves the current URL/session, reports `recovering`, `recovered`, or `failed`, and clears timers when a tab closes.
- `TaskCenter` provides a strict task lifecycle with auditable history, bounded retries, and confirmation gates for destructive recovery; the existing `AgentServer` call history remains backward-compatible.
- Existing MCP clients remain compatible because new fields are optional and no tool names or input schemas were removed.

## Verification limits

Local validation in this workspace passes `npm run build`, `npm run typecheck`, `npm run check`, and `npm run test:task-center`. Real renderer-crash recovery, MCP stdio, Windows 10/11 matrix validation, packaging on each runner, and Authenticode signing still require the release CI environment and are not claimed as locally verified.
