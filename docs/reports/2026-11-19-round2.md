## 1. 结论摘要

本轮在 v0.1.0（Windows NSIS + Linux AppImage、GitHub 发布流水线、自动更新状态机已存在）的基础上，完成了三项产品/供应链增量：

1. **跨会话标签恢复**（补齐审计中的 P1 用户数据缺口）：原子写入、凭据剥离、去重、20 条上限、损坏/未来版本安全降级；恢复普通标签与活动标签，隔离标签和内部页不恢复；设置可关闭。
2. **`browser_performance` MCP 工具**（对标 Chrome DevTools MCP 的诊断能力）：导航耗时、首绘、资源体积与慢资源、JS 堆、DOM 规模，只读幂等；MCP 工具总数从 33 增至 34。
3. **CycloneDX SBOM 供应链资产**：从 lockfile 生成，区分 required/optional 并单列 Electron 运行时；随 Release 发布、进入 `SHA256SUMS.txt`，缺失时发布流程失败，公开校验脚本会解析 SBOM 并核对版本。

同时修复了测试环境缺陷：冒烟脚本启动 Electron 前未清理继承的 `ELECTRON_RUN_AS_NODE=1`，在部分 CI/agent shell 下会把桌面进程启动成纯 Node 进程。该问题在本轮基线复现（smoke 失败）并已修复。

本轮没有新增平台，没有伪造真实更新/签名/Release 证据。真实旧版升级、回滚、Authenticode 和 macOS 签名仍未验证，原因见第 8 节。

## 4. 实际开发结果

### 4.1 跨会话标签恢复

- 新增 `src/main/session-store.ts`：`SessionSnapshot` 归一化（仅 http/https、剥离 URL 账号密码、去重、最多 20 条、活动序号钳制）、原子写入、损坏/未来版本返回 `null`、无可恢复标签时删除旧记录。
- `src/main/tabs.ts`：新增 `sessionTabs()`，保持标签顺序，跳过隔离标签与非网页地址，按过滤后列表计算活动标签。
- `src/main/index.ts`：启动时先恢复会话再打开默认标签；标签变化后 600ms 防抖保存，退出前同步落盘；恢复期间禁止半恢复状态覆盖记录；启动中间态 `about:blank` 不清空旧记录；关闭设置时删除旧记录，重新开启时立即写入当前标签。
- `src/main/settings.ts`、`src/shared/types.ts`：新增 `restoreSession`（默认 `true`）。
- 设置面板：新增「重启后恢复上次打开的标签页」开关与说明，中英文文案齐全。

### 4.2 `browser_performance`

- `src/main/tools.ts`：新增只读工具与页面内 Performance API 采集脚本，输出导航、绘制、资源、慢资源、堆、DOM 六组信息；无 navigation timing 时给出说明而不是抛错。
- `cli/mcp.mjs`：桥接层同步工具定义与四项 MCP annotations。
- `README.md`：工具表更新为 34 个并说明用途。

### 4.3 SBOM 与发布链

- 新增 `scripts/generate-sbom.mjs` 与 `npm run sbom`：CycloneDX 1.5，371 个组件（17 required / 354 optional），Electron 单列为 framework/required。
- `scripts/release-assets.mjs`：新增 `releaseFileNames()`、`supportsSbom()`；清单生成要求 v0.2.0+ 的 SBOM 存在；`SBOM_FILE` 纳入资产集。
- `scripts/publish-release.mjs`、`scripts/verify-public-release.mjs`：发布与公开校验都纳入并解析 SBOM，校验 `metadata.component.version` 与标签一致。
- `.github/workflows/ci.yml`：测试 job 增加 SBOM 生成；release job 在上传前由同一提交生成 SBOM，再生成 `SHA256SUMS.txt`。

### 4.4 测试与工程质量

- `scripts/smoke.mjs`：清理 `ELECTRON_RUN_AS_NODE`；新增会话记录断言（不写内部页/隔离标记）与 `browser_performance` 断言；工具数断言 33 → 34；启动页提示词断言改为通用接入提示词。
- `scripts/test-stores.mjs`：纳入 `session-store.ts`，新增 3 项恢复记录回归（总 11 项）。
- `scripts/test-desktop.mjs`：启动前写入种子会话，断言恢复两个标签与活动标签；断言会话记录包含普通标签且不含隔离标签（总 26 项）。
- `scripts/test-release.mjs`：升级到 v0.2.0 资产集，断言必须包含 SBOM。
- 新增 `scripts/generate-prompt.mjs`（`npm run prompt` / `check:prompt`）与 `scripts/test-installer.mjs`（4 项纯函数回归）。
- 新增 `scripts/test-connect-flow.mjs`：对打包产物执行 `install.mjs --connect-only --dir ... --clients __none__ --verify --json`，断言 JSON 结果、`browser_tabs` 验证、稳定桥和 `--print-config`；Windows 本地已通过，Linux 由 CI 在 AppImage 上运行。
- 测试新增环境变量 `AA_BROWSER_SESSION_FILE` / `AA_BROWSER_CONNECTION_FILE`，冒烟、桌面与 connect 测试使用隔离路径，不污染真实用户数据。

### 4.5 通用安装与接入提示词

- 新增 `installer/install-prompt.md`（未安装：下载 + 校验 + 安装 + 接入 + 验证）与 `installer/connect-prompt.md`（已打开浏览器：只接入 + 验证）作为单一来源，生成 [PROMPT.md](../../PROMPT.md) 与新标签页的提示词区域；`check:prompt` 防止漂移。
- `install.mjs` 重写为跨平台安装器：Windows NSIS / Linux AppImage，按平台选择 Release 资产，校验 SHA-256 与 PE/ELF 文件头；新增 `--connect-only`、`--verify`、`--verify-only`、`--print-config`、`--json`；通过 Node 内置 WebSocket 实际调用 `browser_tabs` 验证；`--json` 输出机器可读结果，日志走 stderr。
- `cli/setup.mjs` 支持 `AA_BROWSER_MCP_BRIDGE` 稳定桥覆盖，并按平台修正 VS Code/Cline 的配置目录；客户端配置写入前仍备份、只改 `aa-browser` 一个键。
- 新标签页统一使用通用接入提示词，不再区分 Windows/Linux 两套文本；说明 AI 能力要求、网页版 ChatGPT 无法自动安装的边界、自动更新方式。
- 新增 [docs/CONNECT.md](../CONNECT.md)：平台/客户端矩阵、参数、手动命令、自动更新、排查与安全边界。

### 4.6 DeepSeek Harness 插件（插件市场）

- 新增 `packages/dsh/` 包：`dsh.bundle` 清单 + `cordis.patch.yml`，安装后向 DSH 注入两行：本包 Host 插件把随包 `bridge.cjs` 原子复制到 `~/.aabrowser/dsh-bridge.cjs`；随后由 DSH 自带的 `@deepseek-ai/dsh-mcp-client` 启动该桥，工具以 `mcp__aa-browser__*` 出现。
- 不需要系统 Node：MCP 行使用 DSH 自身运行时（`process.execPath`，Electron 桌面版配合 `ELECTRON_RUN_AS_NODE=1`）。App 升级后插件重新激活会再次覆盖桥文件，客户端配置无需改动。
- 提供插件市场展示资源（图标、locale、DETAIL、preview）与 `packages/dsh/marketplace-entry.yml`（awesome-dsh-plugin 收录 PR 的条目内容）。
- 本地通过 `plugin_manager install_bundle` 安装到当前 DSH profile：`aa-browser-dsh@0.1.0`，两行启用；当前会话已出现 34 个 `mcp__aa-browser__*` 工具。插件市场目录收录仍需 npm 发布与外部仓库 PR，未代填凭据。
- 插件联调发现并修复 MCP 桥缺陷：浏览器未运行时 `tools/call` 无响应。`cli/mcp.mjs` 在等待连接前先登记占位请求，失败时始终返回工具级 `isError`；新增 `test:bridge` 离线回归。
