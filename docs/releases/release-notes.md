# Aa Browser 发布说明

## v0.6.3 — 2026-11-12

- 新增首次启动 AI 接入向导，按步骤引导用户配置客户端、重启 AI 并发送连接测试提示词。
- 连接状态现在以 AI 成功调用 `browser_tabs(action=list)` 为验证条件；仅完成 MCP 握手会显示等待首次调用。
- 支持 Codex 桌面端、CLI 和 IDE：将 Aa Browser 写入用户级 `~/.codex/config.toml`，更新前备份并保留其他配置。
- 增加 Codex TOML 接入验证，覆盖原有设置保留、配置备份和重复执行幂等性。

## v0.6.2 — 2026-11-12

- 修复 v0.6.1 启动后默认新标签页显示白屏的问题：首屏导航保留创建标签时的目标地址，不再被 `about:blank` 加载事件覆盖。
- 本地页面统一使用规范的 `file://` 地址，并为页面守卫和抓包初始化添加超时保护，避免异常导致永久白屏。
- Windows 正式安装版新增自动更新：可选择稳定版/Beta、手动检查、查看下载进度，并在下载完成后重启安装。
- 普通标签默认共享登录态；仍可在设置中启用隔离会话，隔离标签关闭后清除其分区数据。
- 设置页集中提供 AI 客户端检测与接入；MCP 增加批量表单填写、页面表达式读取和对话框记录工具。
- 网络详情与 HAR 默认遮蔽认证头和敏感 URL 参数；需要时可显式请求敏感字段。

## v0.6.0 — 2026-11-08

- 增加站点白名单，地址栏、Agent 导航、页面链接、重定向、弹窗和右键菜单等入口均在主进程校验；支持精确域名、`*.example.com` 通配符与显式端口。
- 按标签隔离 Cookie、存储、缓存和请求 Mock；下载跟随对应标签的会话。
- 新增请求拦截与 Mock 工具，支持 Agent 查看和模拟网络响应。
- 设置中可选启用高风险 Agent 操作前的人工作业确认。
- 增加下载面板、页面右键菜单、历史记录地址栏联想，以及搜索引擎、快照、下载目录、白名单和 Agent 服务设置。
- 更新 minimatch 依赖以修复 CVE-2026-118764。
