# Aa Browser 发布说明

## v0.0.2 — 2026-11-13

- 新标签页提示词改为完整的安装与连接提示词，包含官方仓库、安装脚本、Windows PowerShell 命令和 `browser_tabs` 实际验证步骤。
- AI 连接状态移到工具栏左侧的高可见位置，点击状态按钮可直接打开连接设置。
- 设置面板打开时扩展到完整窗口，便于查看客户端接入和软件更新选项。
- 修复真实点击事件偶发静默丢失的问题，覆盖复选框、单选框、对话框按钮和下载链接。
- 同步更新 README 和冒烟测试。

## 发布基线重置

从 v0.0.1 起重新发布。此前的 GitHub Releases 已撤下；下方旧版本条目仅记录代码变更，不代表仍可下载的发行包。

## v0.0.1 — 2026-11-12

- Aa Browser 以重新整理后的代码重新建立发布基线。
- 提供基于 MCP 的浏览器控制，包括导航、页面交互、下载、对话框、网络请求和 HAR 导出。
- 提供首次启动 AI 接入向导，并支持 Codex 桌面端、CLI 和 IDE 的配置备份与接入验证。
- Windows 正式安装版支持应用内更新检查和下载后重启安装。
- Windows 安装包尚未配置代码签名，SmartScreen 可能提示确认。
