# Aa Browser 发布说明

## v0.0.3 — 2026-11-13

- 新增页面查找工具栏：`Ctrl+F` 输入内容，查看匹配计数，使用 `Enter` / `Shift+Enter` 或上下按钮切换匹配，`Esc` 关闭。
- 新增最近关闭标签恢复：使用 `Ctrl+Shift+T` 或工具栏按钮重新打开本次运行中最近关闭的普通标签，最多保留 20 个 URL；隔离标签不进入恢复记录。
- 修复网页聚焦后浏览器快捷键无效的问题。
- 修复下载列表、Agent 活动记录和地址栏历史建议被工具栏裁切的问题，面板关闭后恢复网页交互区域。
- 隔离标签访问不再进入全局历史；网页弹窗和右键打开的新标签保留隔离属性。
- 禁止网页脚本直接读取剪贴板，保留用户主动粘贴与普通复制。
- 修复子框架内导航可能改写主标签地址的问题，并改善窗口关闭时的资源释放。
- 修复搜索引擎下拉选择被旧地址覆盖，以及 Agent 搜索无法立即使用新设置的问题。
- 设置保存失败时显示错误并保留原设置；异常配置和历史不再导致类型错误，修复保存前保留异常原文件备份。
- 避免反复保存设置累积更新检查、并发重复检查和下载完成后的待安装状态被再次检查覆盖。

## v0.0.2 — 2026-11-13

- 新标签页提示词改为完整的安装与连接提示词，包含官方仓库、安装脚本、Windows PowerShell 命令和 `browser_tabs` 实际验证步骤。
- AI 连接状态移到工具栏左侧的高可见位置，点击状态按钮可直接打开连接设置。
- 设置面板打开时扩展到完整窗口，便于查看客户端接入和软件更新选项。
- 修复真实点击事件偶发静默丢失的问题，覆盖复选框、单选框、对话框按钮和下载链接。
- 同步更新 README 和冒烟测试。

## 发布基线重置

从 v0.0.1 起重新发布。此前的 GitHub Releases 已撤下；下方旧版本条目仅记录代码变更，不代表仍可下载的发行包。

## v0.0.1 — 2026-11-12

- Aa Browser 以重新整理后的代码重新建立发布基线。
- 提供基于 MCP 的浏览器控制，包括导航、页面交互、下载、对话框、网络请求和 HAR 导出。
- 提供首次启动 AI 接入向导，并支持 Codex 桌面端、CLI 和 IDE 的配置备份与接入验证。
- Windows 正式安装版支持应用内更新检查和下载后重启安装。
- Windows 安装包尚未配置代码签名，SmartScreen 可能提示确认。
