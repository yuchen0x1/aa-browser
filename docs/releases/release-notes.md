## v0.6.8 — 2026-11-21

- 修复关闭窗口时会话记录被空标签覆盖、MCP 请求含 Unicode 行/段落分隔符被误拆超时，以及连接建立期间取消请求仍可能发送的竞态。
- 对话框策略与固定 iframe 动作复用 jsLiteral 编码；显式 `browser_frame evaluate` 语义不变，MCP 工具保持 42 个，用户数据无需迁移。
- 新增真实关窗与特殊字符往返回归；本地 Windows 与远程 CI 双平台通过。

## v0.6.7 — 2026-11-21

- 新标签接入教程全量中英双语（正式 `__aaApplyLocale` 接口，auto 按系统语言解析、回退中文）；生成提示词保持原文。后端可见诊断（客户端接入结果、下载重试原因）按已保存语言输出，路径、命令与原始异常逐字保留。
- 新增 Ctrl/Cmd+P 打印快捷键与统一的打印失败/取消双语反馈（原始 failureReason 进详情，同页面单飞，无静默打印）。
- 修复新标签慢导航窗口内主题/语言同步脚本可能注入外站的竞态（执行时精确校验页面地址）；冒烟测试在 en-US 区域 CI 下因向导断言超时的问题（测试实例固定简体中文）。
- 新增 `test:newtab-i18n`、`test:app-i18n`、`test:main-diagnostics`（114 项）、`test:printing`（14 项）并接入 CI；本地 Windows、WSLg 真实 Linux renderer 与远程 CI 双平台通过。
- MCP 工具保持 42 个，已有用户数据无需迁移；多物理显示器跨屏、真实打印输出、读屏完整流程与安装向导 GUI 未实测。

## v0.6.4 — 2026-11-20

- 新增视觉评审闭环：`browser_visual_diff`（基线 / 像素 diff / 差异图 / 视觉断言）、`browser_contrast_audit`（WCAG AA/AAA 对比度审计）、`browser_viewport_matrix`（320/480/768/桌面 + 2x 高 DPI，走 CDP 绕过窗口最小尺寸）。
- 长操作按 MCP 规范回传 `notifications/progress`；多客户端并发时 HUD 列出每个调用与进度，可单独停止某个调用。
- 工具定义收敛到 `src/shared/tool-defs.mjs` 单一来源，主进程只写 `name + handler`，桥直接导入；`npm run check` 做四方一致性守卫。
- 补齐长期限制：快照分页（`maxNodes/cursor`，跨页 ref 有效）、下载取消/重试（重试重验白名单）、站点权限审批、证据文件生命周期（sha256/TTL/配额，`browser_evidence`）、closed shadow DOM 快照与点击、原生右键菜单中文化与图片项。
- 修复浅色主题下原生标题栏覆盖层仍为深色的问题；中断现在真正取消导航/等待等长操作，跨域 iframe 可用 `browser_frame` 操作，`browser_screenshot` 支持整页。
- MCP 工具集 34 → 42；新增 `npm run test:evidence` 并并入 `npm run check`。本地 check / build / test:tools / test:bridge / smoke / test:desktop（34 项）全部通过。

## v0.3.0 — 2026-11-19

- 设置面板改版：卡片从 560px 提升到 960px，改为左侧分区导航（通用 / 浏览与快照 / 数据与下载 / AI 集成 / 软件更新）加右侧内容区，导航随滚动高亮、点击跳转；设置项改为「左标题说明、右控件」两栏，原生复选框换成开关，保存栏吸底常驻；窗口宽度不足 1000px 时自动收起分区导航。中英文新增 13 条文案。
- 应用图标重做：改为透明背景的满幅「方窗」，修复桌面快捷方式、任务栏与 favicon 四周的白边；`npm run icon` 改用 Canvas 直接导出 PNG，一次生成应用图标、官网图标与 DSH 插件市场图标，产物可重复。
- 安全：Agent 注入脚本的数据字面量统一走 `jsLiteral()` / `refLiteral()`，补转 `<` `>` `/` 与 U+2028/U+2029，`ref` 只放行 `^e\d+$`，避免 `</script>` 或行分隔符截断注入脚本；页面侧探针脚本集中到 `@snapshot/scripts`，`browser_evaluate` 的错误文案不再把 `ref` 拼进源码。
- 新增 `npm run test:page-scripts` 并并入 `npm run check`：在 vm 沙箱里执行编译后的真实注入脚本，断言转义与还原行为；本地回归（check、stores 11/11、updater 13/13、release 5/5、installer 4/4、desktop 26/26、update-ui 6/6、smoke 18 组）全部通过。

## v0.2.0 — 2026-11-19

- 新增通用安装/接入提示词：一段提示词发给任意具备本机执行能力的 AI，自动完成下载、校验、安装、MCP 配置和 `browser_tabs` 验证；已安装时只接入不重装。提示词由单一来源生成，覆盖 Windows x64 / Linux x86_64 和常见 AI 客户端。
- 安装器新增 `--connect-only`、`--verify`、`--verify-only`、`--print-config`、`--json` 与 Linux AppImage 安装，并通过本地 WebSocket 实际验证工具调用。
- 新增 DeepSeek Harness 插件包 `dsh/`（`aa-browser-dsh`）：在插件市场以「Aa Browser connection」出现，安装后把随包 MCP 桥放到稳定路径，工具以 `mcp__aa-browser__*` 提供，无需系统 Node；浏览器升级后重新激活插件即更新桥。
- 修复 Aa Browser 未运行时 MCP `tools/call` 不返回响应、客户端挂到超时的问题，并新增离线回归测试。
- 新增跨会话标签恢复：重启后按上次顺序恢复普通网页标签并回到活动标签，可在设置中关闭。隔离标签、内部页和 `file:`/`data:` 地址不恢复，地址中的账号密码会被剥离。
- 新增第 34 个 MCP 工具 `browser_performance`：导航耗时、首绘、资源体积与慢资源、JS 堆和 DOM 规模摘要，用于不开 DevTools 定位慢页面。
- 正式发行新增 CycloneDX `sbom.cdx.json`，列入 `SHA256SUMS.txt`；发布脚本在缺失 SBOM 时拒绝生成清单，公开发行校验会解析并核对版本。
- 冒烟测试启动 Electron 时清理继承的 `ELECTRON_RUN_AS_NODE`，修复部分 CI/agent shell 下桌面进程无法启动的测试环境问题。
- 持久化回归 11 项、桌面回归 26 项、更新 UI 回归 6 项、安装器纯函数 4 项，并新增打包产物 connect-only 端到端测试；MCP 工具契约同步到 34 个。

## v0.1.0 — 2026-11-18

- 修复新标签首次打开网址后可以退回初始化空白页的问题。
- 关闭设置时撤销未保存的语言预览，保存后重启继续使用所选语言。
- 为自定义搜索地址、自动更新、更新通道及相关设置提示补齐英文翻译。

## v0.0.6 — 2026-11-16

- 导航策略拒绝 `file:`、`data:`、`devtools:`、`view-source:` 等非网页协议，仅保留应用内部新标签页。
- GitHub Release 安装器要求有效的 SHA-256 digest；缺失、格式错误或不匹配时中止安装。
- 开启高危操作审批后，查看或导出未脱敏网络数据需要用户确认。

## v0.0.5 — 2026-11-16

- MCP 工具列表现在为每个工具明确标注只读、破坏性、幂等性和开放世界提示，AI 客户端可以在调用前获得更准确的风险信息。
- 工具清单与实际实现保持一致，并补充了按键、控制台日志等工具的回归覆盖，降低客户端看不到或调用失败的情况。
- 客户端接入不再通过子进程探测 Node，改为无 shell 的 PATH 查找；找不到系统 Node 时自动回退到应用自带运行时。

## v0.0.4 — 2026-11-13

- 自动更新默认自动检查并下载，下载完成后等待用户点击重启安装。
- 新增主界面更新提示和工具栏入口，显示下载进度、失败重试和待安装状态，支持稍后处理。
- 启动 5 秒后检查，此后每 15 分钟检查一次；窗口激活、网络或休眠恢复时按需补查。
- 网络失败按 1、5、15 分钟退避重试；下载失败重试下载，检查失败重试检查。
- 设置中显示上次检查及自动重试时间；关闭自动更新后停止自动检查和后续自动下载，手动操作仍可用。
- 保留正在浏览的页面，不在后台强制安装或退出。旧版首次仍需通过设置或安装包升级一次。

## v0.0.3 — 2026-11-13

- 新增页面查找工具栏：`Ctrl+F` 输入内容，查看匹配计数，使用 `Enter` / `Shift+Enter` 或上下按钮切换匹配，`Esc` 关闭。
- 新增最近关闭标签恢复：使用 `Ctrl+Shift+T` 或工具栏按钮重新打开本次运行中最近关闭的普通标签，最多保留 20 个 URL；隔离标签不进入恢复记录。
- 修复网页聚焦后浏览器快捷键无效的问题。
- 修复下载列表、Agent 活动记录和地址栏历史建议被工具栏裁切的问题，面板关闭后恢复网页交互区域。
- 隔离标签访问不再进入全局历史；网页弹窗和右键打开的新标签保留隔离属性。
- 禁止网页脚本直接读取剪贴板，保留用户主动粘贴与普通复制。
- 修复子框架内导航可能改写主标签地址的问题，并改善窗口关闭时的资源释放。
- 修复搜索引擎下拉选择被旧地址覆盖，以及 Agent 搜索无法立即使用新设置的问题。
- 设置保存失败时显示错误并保留原设置；异常配置和历史不再导致类型错误，修复保存前保留异常原文件备份。
- 避免反复保存设置累积更新检查、并发重复检查和下载完成后的待安装状态被再次检查覆盖。

## v0.0.1 — 2026-11-12
