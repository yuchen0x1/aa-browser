## 📢 版本概述

新增页面查找工具栏与最近关闭标签恢复，找词、切匹配和找回误关页面都能在浏览器内完成。本版同时修复网页聚焦后快捷键失效、面板被工具栏裁切、地址栏被 iframe 改写等一批操作回退问题，并收紧隔离标签与剪贴板的安全边界，关闭标签与窗口时的资源清理也更彻底。已安装用户可直接覆盖升级；安装包仍未配置代码签名，SmartScreen 可能提示确认。

## ✨ 新增功能

- **页面查找工具栏**：`Ctrl+F` 打开查找栏，输入内容即显示匹配计数，用 `Enter` / `Shift+Enter` 或上下按钮切换匹配，`Esc` 关闭；适用于普通网页标签，不必再借助页内搜索或外部工具。
- **最近关闭标签恢复**：`Ctrl+Shift+T` 或工具栏按钮重新打开本次运行中最近关闭的普通标签，最多保留 20 个 URL；隔离标签不进入恢复记录，避免把隔离会话带回普通标签。

## 🐛 问题修复

- **网页聚焦后快捷键失效**：焦点在网页内容时 `Ctrl+F`、`Ctrl+Shift+T` 等浏览器级快捷键无响应；本版修复后无需先点回工具栏。
- **面板被工具栏裁切**：下载列表、Agent 活动记录和地址栏历史建议被工具栏遮住 → 本版修正布局，面板关闭后网页交互区域正确还原。
- **子框架导航改写地址栏**：iframe 内跳转可能把主标签地址改成子框架地址 → 本版只更新主框架地址，标签不会跳到错误页面。
- **搜索引擎选择被旧地址覆盖**：地址栏仍显示旧地址，Agent 搜索要重启才用上新设置 → 本版即时生效。
- **设置保存失败无提示**：本版显示错误并保留原设置；异常配置和历史不再触发类型错误，修复保存前会备份异常原文件。
- **更新检查状态异常**：反复保存设置会累积检查定时器、并发重复检查，下载完成后的待安装状态会被下一次检查覆盖 → 本版去重并保留待安装状态。

## 🔒 安全与兼容性

- **网页脚本读取剪贴板**：网页脚本默认不再能直接读取系统剪贴板 → 用户主动粘贴与普通复制仍可用，减少静默读取剪贴板内容的站点。
- **隔离标签的全局历史**：隔离标签中的访问不再写入全局历史，网页弹窗与右键打开的新标签继续保持隔离属性 → 隔离会话痕迹不会被普通历史带出。
- **安装包未配置代码签名**：Windows 10/11 x64 首次运行与更新安装时 SmartScreen 可能提示「未知发布者」，需要手动确认继续。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.0.3.exe` | Windows x64 | NSIS 安装程序，Windows 桌面主程序 |
| `aa-browser-setup-0.0.3.exe.blockmap` | Windows x64 | 差分更新块索引，供更新器做增量下载 |
| `latest.yml` | Windows x64 | 更新描述文件，更新器据此判断新版本与校验值 |
| `SHA256SUMS.txt` | 平台无关（通用） | 发布资产的 SHA-256 校验清单 |

- 首次安装：下载 `aa-browser-setup-0.0.3.exe`，按向导完成安装后启动；需要接入 AI 客户端时，使用新标签页给出的安装与连接提示词。
- 已安装用户：支持应用内更新，在「设置 → 软件更新」中检查并重启安装；也可直接下载本版安装包覆盖安装。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖升级（应用内更新或安装包）；本版没有数据结构迁移，设置与历史沿用原有 JSON 格式。
- **配置和数据**：升级保留用户数据；本版对异常设置与历史会先备份原文件再修复，仍建议升级前复制 Windows 用户 AppData 下的用户数据目录备份。
- **回退方式**：更新器不支持降级，回退需手动下载旧版安装包覆盖安装；回退前建议备份用户数据，已登录的站点会话可能受 Chromium 跨版本数据格式限制。
