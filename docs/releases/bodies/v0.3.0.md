## 📢 版本概述

本版改善日常使用的观感与安全边界：设置面板从窄单列改成 960px 宽的分区布局，控件、排版和窗口自适应一并调整；应用图标重做为透明满幅，桌面快捷方式、任务栏和 favicon 不再出现白边；Agent 注入脚本的数据字面量统一加固，特殊字符不会再截断脚本。功能面与 MCP 工具集（34 个）保持不变。

## 🔧 改进与优化

- **设置面板改版**：卡片宽度从 560px 提升到 960px，改为左侧分区导航（通用 / 浏览与快照 / 数据与下载 / AI 集成 / 软件更新）加右侧内容区。导航随滚动自动高亮，点击可跳到对应分区；设置项统一为「左侧标题与说明、右侧控件」两栏，同类设置合并进卡片并用分隔线区分。
- **控件与排版**：原生复选框换成开关（保留原生 `input` 语义，可键盘操作）；保存按钮改为底部常驻栏，状态提示在左、主按钮在右；滚动条改为细窄深色样式；说明文字对比度提升到 6:1 以上。
- **窗口自适应**：窗口宽度小于 1000px（应用最小宽度约 960px）时自动收起左侧分区导航，控件换行到标签下方，保存栏仍在视口内。
- **中英文同步**：新增 13 条界面文案，英文界面下导航与分区说明完整显示、无截断。
- **应用图标重做**：图标源改为透明背景的满幅「方窗」，四角完全透明，并加入石墨渐变、内描边和品牌蓝圆环，字标按墨迹光学居中。`npm run icon` 改用 Canvas 直接导出 PNG（不再截窗口），一次生成 `build/icon.png`、`site/assets/icon.png` 与 DSH 插件市场的 `icon-180.png`，产物可重复。

## 🐛 问题修复

- **图标白边**：修复桌面快捷方式、任务栏和网页 favicon 图标四周出现白色底边的问题，改为透明背景后各场景不再露出白色方块。
- **设置项对比度偏低**：说明文字在深色背景下偏暗，本版统一提高对比度，长段说明更易读。

## 🔒 安全与兼容性

- **注入脚本字面量加固**：Agent 注入页面执行的脚本，其数据部分统一走 `jsLiteral()` / `refLiteral()`，补充转义 `<` `>` `/` 与 U+2028 / U+2029，`ref` 只放行 `^e\d+$`。避免 `</script>` 或行分隔符截断注入脚本（对应 CodeQL `js/bad-code-sanitization` 的清理要求）。
- **探针脚本集中**：`click`、`fingerprint`、`checkedState`、`tagName` 等页面侧探针统一收敛到 `@snapshot/scripts`，主进程不再内联拼脚本；`browser_evaluate` 的错误文案不再把 `ref` 拼进源码。
- **兼容性**：MCP 工具集仍为 34 个，工具参数、返回结构与快照格式不变；设置项的存储键沿用旧值，升级后既有配置继续生效。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.3.0.exe` | Windows x64 | 安装程序，用于首次安装或覆盖升级 |
| `aa-browser-setup-0.3.0.exe.blockmap` | Windows x64 | electron-updater 增量更新所需分块信息 |
| `latest.yml` | Windows x64 | Windows 自动更新版本与校验元数据 |
| `aa-browser-0.3.0-linux-x86_64.AppImage` | Linux x86_64 | 免安装可执行文件 |
| `latest-linux.yml` | Linux x86_64 | Linux 自动更新版本与校验元数据 |
| `sbom.cdx.json` | 全平台 | CycloneDX 1.5 软件物料清单 |
| `SHA256SUMS.txt` | 全平台 | 本次发布文件的 SHA-256 校验清单 |

- 首次安装：Windows 双击安装程序；Linux 下载 AppImage 后 `chmod +x` 并从桌面会话启动，安装要求见 [平台指南](https://github.com/yuchen0x1/aa-browser/blob/v0.3.0/docs/PLATFORMS.md)。
- 已安装用户：v0.2.0 及更早版本可在「设置 → 软件更新」检查升级；也可以直接下载本页安装包覆盖安装。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖升级，无需先卸载；设置项存储键不变，旧配置继续生效。
- **配置和数据**：设置、历史、下载记录、标签恢复数据与 MCP 配置全部保留，无需迁移。
- **回退方式**：Linux 更新会在替换前保留按版本命名的旧 AppImage；Windows 回退需重新安装旧版安装包。

## ⚠️ 已知问题

- Windows 安装包未配置 Authenticode 代码签名，首次运行可能触发 SmartScreen 提示。
- 设置面板在宽度低于 1000px 时会收起分区导航，此时只能滚动浏览全部分区。
- macOS、Android、iOS 与 Web 版不在支持范围内，原因见 [平台指南](https://github.com/yuchen0x1/aa-browser/blob/v0.3.0/docs/PLATFORMS.md)。
