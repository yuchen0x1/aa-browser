## 📢 版本概述

新标签页的接入提示词升级为可直接执行的完整安装与连接说明，AI 连接状态也移到工具栏更醒目的位置，设置面板打开即铺满窗口。本版修复了真实鼠标点击偶发静默丢失的问题，并首次随发行附带差分块文件与 `SHA256SUMS.txt`。已安装用户可通过应用内更新直接覆盖升级；安装包仍未配置代码签名，SmartScreen 可能提示确认。

## ✨ 新增功能

- **新标签页完整安装与连接提示词**：提示词从简短说明升级为完整流程，包含官方仓库地址、安装脚本、Windows PowerShell 命令、客户端重载和 `browser_tabs` 实际调用验证步骤；整段复制给 AI 助手即可按其执行，减少手工拼命令和漏步骤。

## 🔧 改进与优化

- **AI 连接状态入口**：状态从原先不显眼的位置移到工具栏左侧，状态文本与对比度更清晰，点击状态按钮可直接打开连接设置 → 用户能一眼判断客户端是否已接入，并少走一层菜单。
- **设置面板尺寸**：打开设置时扩展到完整窗口 → 客户端接入和软件更新选项可完整查看与操作，不必在受限尺寸里滚动查找。
- **发行资产组成**：新增 `aa-browser-setup-0.0.2.exe.blockmap` 与 `SHA256SUMS.txt`（v0.0.1 只有安装包和 `latest.yml`）→ 更新器可做增量下载，下载文件可独立核对完整性。

## 🐛 问题修复

- **真实点击偶发静默丢失**：复选框、单选框、对话框按钮和下载链接在真实鼠标点击下偶发无响应；本版为这些控件补上页面点击兜底，点击不再丢失。

## 🔒 安全与兼容性

- **安装包仍未配置代码签名**：Windows 10/11 x64 首次运行与更新安装时，SmartScreen 可能提示「未知发布者」，需要手动确认继续；系统不会校验发布者身份。
- **下载完整性可核对**：本版起每个发行都附 `SHA256SUMS.txt`，安装前先对照清单核对安装包哈希，再决定是否运行。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.0.2.exe` | Windows x64 | NSIS 安装程序，Windows 桌面主程序 |
| `aa-browser-setup-0.0.2.exe.blockmap` | Windows x64 | 差分更新块索引，供更新器做增量下载 |
| `latest.yml` | Windows x64 | 更新描述文件，更新器据此判断新版本与校验值 |
| `SHA256SUMS.txt` | 平台无关（通用） | 发布资产的 SHA-256 校验清单 |

- 首次安装：下载 `aa-browser-setup-0.0.2.exe`，按向导完成安装后启动；需要接入 AI 客户端时，可直接使用新标签页给出的安装与连接提示词。
- 已安装用户：支持应用内更新，在「设置 → 软件更新」中检查并重启安装；也可直接下载本版安装包覆盖安装。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖升级（应用内更新或安装包）；本版没有数据结构迁移，设置与历史沿用原有格式。
- **配置和数据**：更新与覆盖安装均保留用户数据；升级前可复制 Windows 用户 AppData 下的 Electron 用户数据目录备份。
- **回退方式**：更新器不支持降级，回退需手动下载旧版安装包覆盖安装；回退前建议先备份用户数据。
