## 📢 版本概述

本版集中在长期使用体验与发行可信度：重启后可以恢复上次的普通标签页；Agent 新增页面性能摘要工具，不必打开 DevTools 就能定位慢页面；每个正式发行都附带 CycloneDX SBOM 并纳入 SHA-256 清单。另修复了浏览器未运行时 MCP 调用一直挂到超时的问题。

## ✨ 新增功能

- **跨会话标签恢复**：默认开启。正常或异常退出后重新启动，会按上次顺序恢复普通网页标签并回到活动标签。设置面板可关闭；隔离标签、内部页以及 `file:` / `data:` 等地址不恢复，地址中的账号密码会被剥离，最多保存 20 个不同地址。恢复记录采用原子写入，避免写坏文件后丢失全部记录。
- **通用安装与接入提示词**：向任意具备本机执行能力的 AI 客户端发放一段提示词即可完成接入。未安装时自动下载、校验、安装并写入 MCP 配置；已安装时只接入并验证，不重复安装。支持 Windows x64 与 Linux x86_64，可识别 ZCode、Claude Code、Cursor、Windsurf、Cline、VS Code、Gemini CLI、Qwen Code、Codex、WorkBuddy 等客户端，其他客户端可用 `--print-config` 取通用配置。提示词与新标签页、[PROMPT.md](https://github.com/yuchen0x1/aa-browser/blob/v0.2.0/PROMPT.md) 同源。
- **安装器自验证与机器可读输出**：`install.mjs` 新增 `--connect-only`、`--verify`、`--verify-only`、`--print-config`、`--json`，并通过本地 WebSocket 实际调用 `browser_tabs` 成功才算接入完成；Windows 安装 PE/NSIS，Linux 安装 AppImage，均校验 Release SHA-256 与文件头。
- **DeepSeek Harness 插件包**：新增 `packages/dsh/`（`aa-browser-dsh`），在插件市场以「Aa Browser connection」出现。安装后把随包 MCP 桥放到稳定路径，工具以 `mcp__aa-browser__*` 提供，不依赖系统 Node；浏览器升级后重新激活插件即可覆盖桥文件。
- **`browser_performance` 工具**（第 34 个 MCP 工具）：返回导航耗时（TTFB / DOMContentLoaded / load）、First Contentful Paint、资源数量与传输/解码体积、最慢资源、JS 堆用量和 DOM 规模。只读、幂等，适合在 Agent 任务里先诊断再优化。
- **CycloneDX SBOM**：`sbom.cdx.json` 随每个正式 Release 发布，列出应用组件与完整 npm 依赖树（区分 required / optional），并写入 `SHA256SUMS.txt`。

## 🔧 改进与优化

- **提示词单一来源**：通用提示词由 `installer/install-prompt.md`、`installer/connect-prompt.md` 生成到 `PROMPT.md` 与新标签页，`npm run check:prompt` 防止多处文案漂移。
- **发布门禁**：发布脚本在 v0.2.0 及以后要求 SBOM 存在，缺失时拒绝生成清单；公开发行校验会解析 SBOM 并核对版本。
- **测试覆盖扩展**：持久化回归扩展到 11 项，桌面回归扩展到 26 项，更新 UI 回归 6 项，安装器纯函数回归 4 项，并新增 `--connect-only --verify --json` 对打包产物的端到端测试；MCP 工具契约同步到 34 个。

## 🐛 问题修复

- **MCP 调用无响应**：修复 Aa Browser 未运行时 `tools/call` 不返回任何响应、客户端一直挂到超时的问题。桥现在始终返回工具级 `isError` 结果，并新增离线回归测试。
- **测试环境启动失败**：冒烟测试启动 Electron 时清理继承的 `ELECTRON_RUN_AS_NODE`，避免部分 CI / agent shell 把桌面进程变成纯 Node 进程导致启动失败。

## 🔒 安全与兼容性

- **恢复数据边界**：标签恢复跳过隔离标签、内部页和非 HTTP(S) 地址，并剥离 URL 中的账号密码，避免把凭据写进恢复文件。
- **供应链**：SBOM 与 SHA-256 清单同时发布，安装器的 digest 校验行为保持不变。
- **兼容性**：MCP 工具集从 33 个增至 34 个，新增工具为只读查询，既有工具的参数与返回结构不变。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.2.0.exe` | Windows x64 | 安装程序，用于首次安装或覆盖升级 |
| `aa-browser-setup-0.2.0.exe.blockmap` | Windows x64 | electron-updater 增量更新所需分块信息 |
| `latest.yml` | Windows x64 | Windows 自动更新版本与校验元数据 |
| `aa-browser-0.2.0-linux-x86_64.AppImage` | Linux x86_64 | 免安装可执行文件 |
| `latest-linux.yml` | Linux x86_64 | Linux 自动更新版本与校验元数据 |
| `sbom.cdx.json` | 全平台 | CycloneDX 1.5 软件物料清单 |
| `SHA256SUMS.txt` | 全平台 | 本次发布文件的 SHA-256 校验清单 |

- 首次安装：Windows 双击安装程序；Linux 下载 AppImage 后 `chmod +x` 并从桌面会话启动，安装要求见 [平台指南](https://github.com/yuchen0x1/aa-browser/blob/v0.2.0/docs/PLATFORMS.md)。
- 已安装用户：Windows 与 Linux 均可在「设置 → 软件更新」检查升级；也可用一次提示词让 AI 只做接入与验证（`--connect-only`）。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖升级，无需先卸载旧版本；MCP 客户端配置不需要改写。
- **配置和数据**：设置、历史、下载记录与 MCP 配置保留。新增的标签恢复数据写在独立文件中，关闭该功能后可继续使用旧行为。
- **回退方式**：Linux 更新会在替换前保留按版本命名的 AppImage；Windows 回退需重新安装旧版安装包。

## 🧪 验证结果

- 本地回归全部通过：`test:stores` 11/11、`test:desktop` 26/26、`test:update-ui` 6/6、`test:installer` 4/4，以及 `test:tools`（34 个工具契约）、`test:security`、`test:updater`、`test:release`、`test:bridge`、`smoke`。
- 打包产物：`--connect-only --verify --json` 端到端检查通过。
- 未验证：真实旧版客户端到 v0.2.0 的完整自动更新安装与回滚，以及 Windows 代码签名链路；本说明不宣称这些已完成验收。

## ⚠️ 已知问题

- Windows 安装包未配置 Authenticode 代码签名，首次运行可能触发 SmartScreen 提示。
- 标签恢复只恢复 URL，不恢复表单内容、滚动位置和页面内状态。
- macOS、Android、iOS 与 Web 版不在支持范围内。
