## 📢 版本概述

本版新增 Linux x86_64 AppImage，Windows 与 Linux 首次随同一版本号发布。Linux 上可以正常浏览网页、使用标签页和查找，并通过 MCP 接入 Agent。更新 AppImage 前会保留一份按版本命名的旧文件，替换出错时可以手动换回。功能面、快照格式和 MCP 工具集与 v0.0.8 保持一致。

## ✨ 新增功能

- **Linux x86_64 AppImage**：在 Linux 桌面直接运行，无需安装。支持图形浏览、标签页、页面查找和 MCP 接入；旧版本记录说明 AppImage 版本已具备应用内更新能力。
- **MCP 桥稳定路径**：MCP 客户端配置指向固定的桥接路径，浏览器升级后不需要重新改写客户端配置。
- **AppImage 更新回退副本**：替换 AppImage 之前，先把当前文件按版本号另存一份；安装过程出错时可以直接启动这份旧文件。
- **两平台同版本发布**：Windows 与 Linux 资产随同一版本发布，并附 GitHub 不可变发行证明，用于核对文件来源。

## 🔧 改进与优化

- **安装与更新错误反馈**：安装阶段失败时给出明确反馈，不再静默退出。
- **发布流程**：两平台打包后各跑一次 MCP 端到端检查；发布内容包括平台更新描述、SHA-256 校验清单和发行证明。

## 🔒 安全与兼容性

- **校验清单**：全部资产可用 `SHA256SUMS.txt` 核对；也可用 `gh release verify-asset v0.1.0 <文件路径> --repo yuchen0x1/aa-browser` 验证 GitHub 发行证明。
- **平台范围**：本版仅提供 Windows x64 与 Linux x86_64；macOS、Android、iOS 与 Web 版不在支持范围内，原因见 [平台指南](https://github.com/yuchen0x1/aa-browser/blob/v0.1.0/docs/PLATFORMS.md)。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.1.0.exe` | Windows x64 | 安装程序，用于首次安装或覆盖升级 |
| `aa-browser-setup-0.1.0.exe.blockmap` | Windows x64 | electron-updater 增量更新所需分块信息 |
| `latest.yml` | Windows x64 | Windows 自动更新版本与校验元数据 |
| `aa-browser-0.1.0-linux-x86_64.AppImage` | Linux x86_64 | 免安装可执行文件 |
| `latest-linux.yml` | Linux x86_64 | Linux 自动更新版本与校验元数据 |
| `SHA256SUMS.txt` | 全平台 | 本次发布文件的 SHA-256 校验清单 |

- 首次安装：Windows 双击安装程序按向导完成；Linux 下载 AppImage 后添加执行权限（`chmod +x`），从桌面会话启动。
- 已安装用户：Windows 用户可在「设置 → 软件更新」检查升级；Linux 用户首次需手动下载 AppImage，之后的版本可通过应用内更新替换。

## 🔄 升级与数据迁移

- **兼容性**：Windows 可直接覆盖安装升级；v0.0.8 及更早版本不需要先做其它操作。
- **配置和数据**：覆盖安装不清理既有的浏览配置、历史与设置；Linux 首次使用会新建一套配置，不与 Windows 端共享。
- **回退方式**：AppImage 更新会保留按版本命名的旧文件，替换后如无法启动，可直接运行该旧文件；Windows 需重新安装旧版安装包。

## 🧪 验证结果

- 两平台打包产物：均执行 MCP 端到端检查并通过。
- 发布完整性：资产 SHA-256 清单与发行证明可核对。
- 未验证：真实旧版本到 v0.1.0 的完整自动更新安装、重启与回滚链路，以及 Windows 代码签名状态；本说明不宣称这些已完成验收。

## ⚠️ 已知问题

- Windows 安装包未配置 Authenticode 代码签名，首次运行可能触发 SmartScreen 提示。
- Linux 版为首次发布，桌面环境差异（托盘、文件对话框、输入法等）覆盖面有限，遇到问题请提交 Issue。
