## 📢 版本概述

本次更新集中修复了 MCP 操作结果不透明、后台渲染、导出安全、下载与设置界面等一批可靠性问题。滚动、查找、等待、网络记录、快照和表单操作现在会报告更准确的实际结果；PDF/HAR/截图导出增加路径与符号链接保护；浏览器外壳在主题和语言切换、标签切换、下载重试及 AI 活动刷新时更加稳定。用户数据与既有 MCP 客户端配置保持兼容，无需迁移。

## ✨ 新增功能

- **更完整的 `browser_wait`**：支持文本出现/消失、选择器出现/消失以及 URL 包含等条件的 OR 等待，共享同一个超时和取消信号，并返回实际满足的条件。
- **结构化网络与重定向信息**：`browser_network_requests`、`browser_network_detail` 返回请求方法、资源类型、状态、大小、耗时、错误和重定向地址；HAR 保留重定向链并继续对敏感请求头脱敏。
- **更可靠的网络 Mock**：Mock 请求支持 CORS 预检（OPTIONS）、Origin 回显、允许方法/请求头、缓存时间与大小写不敏感的响应头合并；预检不会虚增业务命中次数。
- **首帧外观缓存**：主题和界面语言会缓存到本地，启动时在样式表前同步应用上次选择，减少浅色/中文默认界面闪烁；设置页的预览和保存仍保持原有回滚语义。

## 🔧 改进与优化

- **操作结果可验证**：`browser_scroll` 报告请求量与实际位移；`browser_find` 忽略其他请求的异步结果并正确处理 `finalUpdate`；网络断言默认把 2xx/3xx 视为成功，但显式状态范围仍可验证 4xx/5xx。
- **快照诊断更准确**：长文本和下拉选项的显示裁剪不再误报为节点树截断；节点数上限、嵌套深度、文本裁剪和选项裁剪分别返回原因，分页与增量快照会显示对应提示。
- **表单、iframe 与对话框**：支持 contenteditable 元素写入，拒绝不可编辑目标并验证清空/写入结果；对话框“一次”策略按 confirm/prompt 类型分别消费；敏感 Cookie 来源信息更明确。
- **导出与证据生命周期**：PDF/HAR 路径限制在浏览器导出目录或 `AA_BROWSER_EXPORT_DIR`，拒绝查询串/片段、越界路径、符号链接和非普通文件；证据登记表损坏时先备份原文件，无法备份则进入只读保护，避免用空表覆盖历史数据。
- **后台与视觉检查**：最小化或隐藏页面的临时视口覆盖在成功、失败和取消路径都会恢复；对比度审计会考虑祖先透明度、文字阴影与描边；视觉差异图写入独立目录，不再覆盖同名基线。
- **下载、客户端和标签体验**：打开下载前检查完成状态和文件存在；重试等待真实异步下载并清理超时占位；配置指向缺失桥时明确提示修复；标签允许路径前缀白名单；活动列表按客户端和调用 id 复用 DOM，减少频繁刷新导致的误点击；关闭最后一个普通标签时保留可用的新标签。
- **界面可访问性与动态语言**：审批面板补充 alertdialog 语义和焦点管理；下载、客户端设置、活动抽屉在切换语言后立即刷新；更新失败会在状态栏显示截断原因并在标题中保留完整详情；打印取消不再额外弹出模态提示。

## 🐛 问题修复

- 修复 `browser_type` 清空失败、设置值失败仍继续操作的问题。
- 修复重定向请求只保留最后一跳、敏感 URL fragment 未脱敏、Mock CORS 预检失败以及网络耗时标签不清晰的问题。
- 修复安装器日志在版本前已有 `v` 时显示 `vv`；修复下载列表状态与可用操作不一致、更新错误只有“失败”没有原因、设置首帧主题跳变等问题。
- 修复标签地址栏草稿、活动调用停止按钮、审批焦点、跨标签 DOM 节点和下载重试反馈在状态刷新时丢失的问题。
- 桥接服务对无法解析的帧记录诊断，对带数字 id 但缺少工具名或参数类型错误的请求返回结构化错误，并保护发送缓冲区不会无限增长。

## 🔒 安全与兼容性

- 所有导出路径继续经过主进程边界校验，明确拒绝越界路径、查询串/片段和符号链接；网络 URL、请求头和 HAR 重定向地址按敏感参数规则脱敏。
- 既有 MCP 工具名称、客户端入口、设置、Cookie、下载和会话数据格式保持兼容；本版本没有要求重新接入客户端或手动迁移数据。
- `browser_wait`、网络结构化字段、快照原因字段和下载 IPC 返回值均为向后兼容的新增/补充；应用仍通过本地 token WebSocket 和受信发送者校验保护主进程能力。
- Windows 安装包当前未配置 Authenticode 签名；GitHub Release 的不可变资产和 SHA-256 校验不能替代 Windows 代码签名。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖升级；既有工具名称、参数和客户端入口保持可用，新增参数均为可选。
- **配置和数据**：保留现有设置、历史、Cookie、下载与会话数据；无需手动迁移。主题/语言首帧缓存只保存在本地渲染器存储中，不影响主设置文件。
- **回退方式**：需要回退时，先退出应用并备份本机配置与会话，再从旧版正式发行取得安装包。旧版会忽略本版新增的诊断字段，但不会影响既有工具。

## ⚠️ 已知问题

- Windows 安装包仍未配置 Authenticode 签名，首次下载请核对 GitHub Release 的 SHA-256 校验和。
