## 📢 版本概述

本版集中修复双主题可读性、键盘焦点连续性与小窗口布局问题，保留现有海玻璃色视觉语言和全部浏览器功能。新增桌面 UI/UX 与官网自动回归并接入 CI，MCP 工具保持 42 个，已有用户数据无需迁移。

## 🔧 改进与优化

- **键盘导航**：标签栏支持 Left / Right / Home / End 和首尾循环；历史建议的键盘选中项自动滚入可视区，非活动标签的关闭按钮在聚焦时可见。
- **无障碍标签**：搜索引擎预设、自定义搜索地址、下载目录和站点白名单增加持久标签及说明关联，不再仅依赖 placeholder。
- **设计 Token**：补齐圆角、间距、常用字号、动画时长与禁用透明度，保持原有尺寸和视觉节奏；组件继续使用双主题语义颜色。
- **回归防线**：新增 `npm run test:ui-ux` 和 `npm run test:site-ui` 并接入 CI；DPI 矩阵扩展为 100% / 125% / 150% / 200%。

## 🐛 问题修复

- 修复设置弹窗的 Tab 循环包含禁用控件、焦点可能卡住而无法到达后续设置的问题。
- 修复状态刷新重建按钮导致审批、下载操作、单项停止和关闭标签按钮焦点丢失的问题；恢复焦点不覆盖用户主动打开查找条的焦点，也不抢走网页焦点。
- 修复方向键切换标签后焦点进入网页，无法连续切换标签的问题。
- 修复浅色下载完成文字对比度不足：从约 1.75:1 提升至 5.70:1；深色新标签说明从约 4.07:1 提升至 5.69:1。官网次要代码文字改用统一语义 Token，已测样本最低约 6.95:1。
- 修复最小窗口下更新、查找与审批提示叠加时下载/活动抽屉底部被裁切的问题，按剩余窗口高度布局并保留内部滚动。
- 修复官网 390px 首屏约 13px 的横向溢出，以及导航 JS 与 CSS 断点不一致导致菜单在紧凑布局中意外关闭的问题。

## 🔒 安全与兼容性

- 现有 MCP 工具数量与参数保持兼容；标签切换桥接增加可选焦点参数，旧调用行为不变。
- 不强制改变外部网站主题，不修改网站内容或用户登录状态。
- 本项目为开源软件；客户端代码可被读取，不应将其视作保密边界。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.6.6.exe` | Windows x64 | 安装程序，用于首次安装或覆盖升级 |
| `aa-browser-setup-0.6.6.exe.blockmap` | Windows x64 | 增量更新分块信息 |

- 首次安装：Windows 运行安装程序；Linux 为 AppImage 添加执行权限后从图形桌面启动。详见 [平台指南](https://github.com/yuchen0x1/aa-browser/blob/v0.6.6/docs/PLATFORMS.md)。

## 🔄 升级与数据迁移

- 可从 v0.6.5 覆盖升级，无需卸载，无需数据迁移；设置、历史、Cookie、下载与标签恢复数据沿用原存储。
- Linux 更新保留按版本命名的旧 AppImage；Windows 回退需重新安装旧版安装包。

## 🧪 验证结果

- 发布准备前本地 Windows 已通过构建、类型检查、lint、工具契约、持久化、安全、更新、发行脚本及离线桥接回归。
- 桌面 UI/UX 38 项、官网 UI 44 项、原有桌面 35 项、更新 UI 9 项及冒烟测试通过；官网三页 × 七种尺寸均无页面横向溢出，相关 renderer 控制台未发现错误。

- 独立代码二审未发现已确认阻塞，指出的标签键盘边界与表单标签引用测试已补齐并通过。
- Windows / Linux 打包、安装后 MCP 验证与公开更新链路以本次标签触发的 CI 结果为准；本地通过不代表未测试的硬件场景全部通过。

## ⚠️ 已知问题

- Windows 安装包未配置 Authenticode 代码签名，首次运行可能出现 SmartScreen 提示。
- lint 仍报告既有非阻断 warnings / infos，不代表全仓已无风格问题。
- macOS、Android、iOS 与 Web 浏览器产品版不在支持范围内；配套官网为独立静态站。
