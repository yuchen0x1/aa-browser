## 📢 版本概述

本版新增界面语言设置：默认跟随系统或浏览器语言在简体中文与 English 之间自动选择，也可以在设置中手动切换，选择会持久化并在重启后继续生效。语言只作用于应用壳层（标签栏、地址栏、菜单、窗口标题与设置界面），网页内容、快照结构、导航策略与安全边界保持原样。默认值为「自动」，升级不需要额外操作；Windows 安装包仍未配置代码签名。

## ✨ 新增功能

- **界面语言自动检测**：此前界面固定为中文，非中文用户需要自行对照 → 现在按系统或浏览器语言自动选择简体中文或 English → 默认生效，适用于所有用户，无需配置。
- **手动语言切换与持久化**：设置中新增语言选项（自动 / 简体中文 / English），选择写入主进程设置并在重启后保留 → 适合系统语言与期望界面语言不一致的场景。

## 🔧 改进与优化

- **语言状态集中管理**：语言候选解析、全局设置同步与本地化事件由统一的语言工具处理 → 标签栏、地址栏、菜单、窗口标题与设置文案随语言即时更新，避免各组件各自解析导致界面不同步。
- **改动范围可控**：页面快照、增量快照与 MCP 动作的返回结构不变，深色/浅色主题、快捷键、下载面板与 Agent 状态栏布局不变 → 升级后既有操作习惯与依赖返回结构的客户端脚本不受影响。

## 🔒 安全与兼容性

- **安全边界延续 v0.0.6**：`file:`、`data:`、`devtools:`、`view-source:` 等非 HTTP(S) 导航仍被拒绝，GitHub Release 安装器仍要求有效 SHA-256 digest，高危审批仍覆盖未脱敏网络数据的查看与导出；本版没有放宽这些限制。
- **Windows 安装包仍未签名**：SmartScreen 可能提示未识别发布者，确认来源后选「更多信息 → 仍要运行」；签名尚未引入，也未完成首次信任验收。

## 🔄 升级与数据迁移

- **兼容性**：Windows x64 单一平台、NSIS 安装包，可直接覆盖安装；设置在原有配置中新增 `locale` 字段，旧配置缺少该字段时按「自动」处理。
- **配置和数据**：语言选择随设置一起保存，覆盖安装后保留；站点白名单、历史与 Chromium profile 位置不变，升级前建议备份用户数据。
- **回退方式**：可以从 Releases 重新安装旧版官方安装器；旧版不包含本版的语言设置，回退前建议暂停自动检查并备份用户数据。

## 🧪 验证结果

- 据本版发布说明：TypeScript、工具契约、构建、冒烟、桌面回归、更新界面、存储、安全和发布元数据检查通过。
- 桌面检查脚本改为语言感知，避免界面语言造成「无匹配」等断言误判（本版提交 `fix: keep desktop checks locale aware`）。
- 真实旧客户端到本版的完整自动更新安装、真实浏览器登录态与多站点兼容性：未验证。

## ⚠️ 已知问题

- Windows 安装包未代码签名，SmartScreen 会提示未识别发布者；影响首次安装与覆盖升级。
- 界面语言只覆盖应用壳层，网页内容、页面标题与站点文案不受影响；英文界面的文案覆盖范围以本版已接入的控件为准，未逐条核对。
- Agent 能看到页面内容与网络流量，包括可能含秘密的 Cookie、Storage、请求头和响应体；不要让不可信 Agent 访问高敏站点。
