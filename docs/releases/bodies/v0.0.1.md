## 📢 版本概述

重新整理代码后的发布基线：把「让 AI 通过 MCP 驱动本机浏览器」做成可直接安装使用的 Windows 应用，并附带首次启动的 AI 接入向导。Windows x64 正式安装版已支持应用内检查更新、查看下载进度，并在下载完成后重启安装。安装包尚未配置代码签名，首次运行时 Windows SmartScreen 可能要求确认；此前撤下的发行包无法通过应用内更新升级到本版，需要手动下载安装。

## ✨ 新增功能

- **MCP 浏览器控制**：AI 客户端可通过 MCP 连接本机浏览器，完成页面导航、点击与表单填写、文件下载、页面对话框处理、网络请求查看与 HAR 导出；适用于把真实浏览器操作交给 AI 执行的场景。
- **首次启动 AI 接入向导**：首次启动时引导配置 AI 客户端，覆盖 Codex 桌面端、CLI 与 IDE，在写入前备份并保留现有配置，接入后可实际调用工具验证。
- **Windows 应用内更新**：正式安装版可在应用内检查新版本、显示下载进度，下载完成后重启安装；仅适用于 Windows x64 安装版，不适用于解包或开发模式运行。

## 🔒 安全与兼容性

- **安装包未配置代码签名**：Windows 10/11 x64 在首次运行和更新安装时，SmartScreen 可能提示「未知发布者」，需要手动确认继续；系统不会校验发布者身份。
- **更新器不支持版本降级**：应用内更新只向更高版本升级，已安装更高版本的用户无法通过更新器切回本版。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.0.1.exe` | Windows x64 | NSIS 安装程序，Windows 桌面主程序 |
| `latest.yml` | Windows x64 | 更新描述文件，应用内更新器据此读取版本与校验信息 |

- 首次安装：下载 `aa-browser-setup-0.0.1.exe`，按向导完成安装后启动；需要接入 AI 客户端时，在首次启动向导中完成配置。
- 已安装用户：本版是新的发布基线，此前的发行包已撤下，没有可用的应用内升级路径；已有旧安装包的用户请手动下载本版覆盖安装。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖安装；更新器不支持降级，从更高版本回到本版只能用安装包手动完成。
- **配置和数据**：设置、历史与站点登录态保存在 Windows 用户 AppData 下的 Electron 用户数据目录，覆盖安装不会清除该目录；建议升级前自行复制一份备份。
- **回退方式**：下载旧版安装包手动覆盖安装；回退前先备份用户数据，已登录的站点会话可能受 Chromium 跨版本数据格式限制。
