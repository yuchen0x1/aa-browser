## 📢 版本概述

自动更新从「能检查」变成「能看见、能下载」：启动后自动检查并在后台下载新版本，主界面显示下载进度和待安装状态，失败会按退避节奏重试，且浏览过程中不会强制退出或自动安装。0.0.2 / 0.0.3 用户需要先手动升级一次，才能获得这套新的更新提示逻辑。安装包仍未配置代码签名，SmartScreen 可能提示确认。

## ✨ 新增功能

- **自动检查与后台下载**：启动约 5 秒后检查新版本，此后每 15 分钟检查一次；窗口重新激活、网络恢复和休眠恢复时按需补查，新版本在后台下载，不阻塞正在浏览的页面。
- **主界面更新提示**：主界面显示可用版本、下载进度、失败状态和待安装状态，工具栏保留常驻更新入口；提示可以「稍后」收起，不会丢失更新信息。
- **失败自动重试**：网络失败按 1、5、15 分钟退避重试，检查失败重试检查、下载失败重试下载，也支持立即手动重试。
- **更新设置与状态**：设置中显示上次检查时间和自动重试时间；关闭自动更新后停止自动检查与后续自动下载，手动检查仍可正常使用。
- **安装由用户确认**：下载完成后只提示「重启安装」，点击后才交给系统安装器；浏览时不会强制退出，关闭窗口也不会自动安装。

## 🔒 安全与兼容性

- **安装包未配置代码签名**：Windows 10/11 x64 首次运行与更新安装时，SmartScreen 可能提示「未知发布者」，需要手动确认继续；系统不会校验发布者身份。
- **更新来源与校验**：更新只从官方 GitHub Releases 通过 HTTPS 获取，安装前由更新器按 `latest.yml` 校验 SHA-512，来源被替换的安装包不会作为更新被安装。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
|---|---|---|
| `aa-browser-setup-0.0.4.exe` | Windows x64 | NSIS 安装程序，Windows 桌面主程序 |
| `aa-browser-setup-0.0.4.exe.blockmap` | Windows x64 | 差分更新块索引，供更新器做增量下载 |
| `latest.yml` | Windows x64 | 更新描述文件，更新器据此判断新版本与校验值 |
| `SHA256SUMS.txt` | 平台无关（通用） | 发布资产的 SHA-256 校验清单 |

- 首次安装：下载 `aa-browser-setup-0.0.4.exe`，按向导完成安装后启动；需要接入 AI 客户端时，使用新标签页给出的安装与连接提示词。
- 已安装用户：在「设置 → 软件更新」检查更新，或等待启动后自动检查；0.0.2 / 0.0.3 请按下一节先手动升级一次。

## 🔄 升级与数据迁移

- **兼容性**：可直接覆盖升级；但 0.0.2 / 0.0.3 不会自动获得本版的新提示逻辑，需要先在「设置 → 软件更新」检查、下载并重启安装，或直接下载本版安装包覆盖安装一次。新发布不会修改正在运行的旧程序。
- **配置和数据**：升级保留用户数据，无数据结构迁移；建议升级前复制 Windows 用户 AppData 下的 Electron 用户数据目录备份。
- **回退方式**：更新器不支持降级，回退需手动下载旧版安装包覆盖安装；回退前建议备份用户数据并暂停自动检查，避免又被自动升回。
