MCP Reference

42 个工具，
一次说清。

v0.2.0 stdio · MCP 5 类能力

所有工具都由 Aa Browser 主进程执行，经本地 WebSocket 回到页面。browser_click、browser_type 等动作默认带回增量快照，Agent 不必二次请求。

类别 导航与快照 5 交互 9 读取与状态 19 网络与 Mock 6 诊断与标签 3

约定

动作类工具默认返回增量快照；传 snapshot: false 可跳过。ref 来自最近一次快照，跨快照稳定。

验证

MCP 桥连上不等于接通。让客户端实际调用 browser_tabs 并拿到标签列表，才算验证通过。

显示 42 个工具 · 全部分类
browser_navigate NAV

导航到 URL；非 URL 文本自动转为搜索词。结果内嵌完整快照，snapshot: false 可跳过。

{ "url": "https://github.com/trending", "snapshot": true }
browser_snapshot NAV

结构化页面快照：可访问性树 + 元素 ref。增量模式省 token，full: true 强制完整树。

{ "full": true }
browser_navigate_back NAV

历史后退一页，返回增量快照。

{ }
browser_navigate_forward NAV

历史前进一页，返回增量快照。

{ }
browser_reload NAV

刷新当前或指定标签页；hard: true 绕过缓存。

{ "hard": true }
browser_click ACT

按 ref 点击，支持左键、右键与双击；走受信任输入事件，动作后自动返回增量快照。

{ "ref": "e12", "button": "left" }
browser_type ACT

按 ref 输入文本，submit 回车提交，clear 先清空。输入走 insertText 管线。

{ "ref": "e15", "text": "Aa Browser", "submit": true }
browser_fill_form ACT

一次调用填写多个字段（文本 / 下拉 / 复选），只在末尾返回一次快照，适合长表单。

{ "fields": [ { "ref": "e2", "value": "user@example.com" }, { "ref": "e3", "label": "中国" } ] }
browser_select_option ACT

按 ref 选择下拉项，按 option 的 value 或可见文本匹配。

{ "ref": "e8", "label": "最近 7 天" }
browser_drag ACT

拖拽元素到目标元素（toRef）或按相对偏移（dx / dy），支持滑块与看板。

{ "ref": "e3", "toRef": "e9" }
browser_hover ACT

按 ref 悬停，触发悬停菜单与 tooltip。使用真实 mouseMove 输入路径。

{ "ref": "e6" }
browser_press_key ACT

向当前焦点发送按键：Enter / Escape / Tab / 方向键 / 单字符等。

{ "key": "Escape" }
browser_scroll ACT

滚动页面：先主文档，再最大滚动区域，默认 700px。

{ "direction": "down", "amount": 900 }
browser_upload_file ACT

向 <input type=file> 上传本机文件并触发 change 事件，单次上限 20MB。

{ "ref": "e11", "paths": ["C:\\Users\\me\\report.pdf"] }
browser_extract READ

提取整页或指定元素的纯文本，适合读文章、表格外的长文本。

{ "ref": "e20" }
browser_evaluate READ

在页面主世界执行 JS 表达式并返回 JSON，可按 ref 把元素绑定为 element。

{ "expression": "document.title" }
browser_screenshot READ

PNG 截图；传 ref 时滚动到位、按包围盒裁剪为元素级截图。

{ "ref": "e7" }
browser_pdf READ

把当前页面渲染为 A4 PDF 并保存到指定路径。

{ "path": "C:\\Users\\me\\page.pdf" }
browser_find READ

页面内查找文本（原生 Ctrl+F 行为）：高亮全部匹配并定位第一处，返回匹配数。

{ "text": "订单号" }
browser_wait READ

等待文本出现 / 消失，或等待固定时长。text 与 textGone 同时给出时以先发生者为准。

{ "text": "支付成功", "timeoutMs": 10000 }
browser_dialogs READ

读取页面弹过的 alert / confirm / prompt。弹窗已被拦截，confirm 返回 false、prompt 返回 null，不会卡死。

{ "clear": true }
browser_get_selector READ

为 ref 元素生成 CSS 选择器，并经 DOM 回验，可复用到脚本与测试。

{ "ref": "e12" }
browser_cookies READ

Cookie 读取 / 写入 / 清理，是登录态测试的关键能力。

{ "action": "get", "url": "https://example.com" }
browser_storage READ

localStorage / sessionStorage 的读取、写入、删除与清空。

{ "action": "get", "kind": "local" }
browser_downloads READ

下载捕获列表：下载被静默保存到 ~/.aabrowser/downloads/，没有保存对话框。

{ "limit": 10 }
browser_dialog_respond READ

为下一次或持续的 confirm / prompt 预设返回值，便于测试需要确认或文本输入的流程。

{ "confirm": true, "once": true }
browser_assert READ

断言 URL、标题、文本、选择器、表单值、控制台或网络请求；不满足时返回期望值与实际结果。

{ "checks": [{ "kind": "title", "expected": "Dashboard" }] }
browser_frame READ

列出 frame，并在其上下文读取、查找元素、执行表达式或交互；支持跨域 iframe。

{ "action": "list" }
browser_visual_diff READ

保存页面视觉基线并逐像素比较；生成差异图，变化超过阈值时可作为失败断言。

{ "action": "compare", "name": "settings" }
browser_contrast_audit READ

审计可见文本的 WCAG AA / AAA 对比度，列出未达标元素与比值。

{ "level": "AA" }
browser_viewport_matrix READ

一次在多个视口尺寸与 DPI 下截图，报告每个视口的尺寸和横向溢出。

{ "preset": "mobile", "includeImages": true }
browser_evidence READ

管理截图、HAR、PDF 与视觉基线证据；可查看 SHA-256、清理到期文件和校验哈希。

{ "action": "list" }
browser_console READ

读取页面控制台消息，可按 error / warning / info 过滤。

{ "level": "error", "limit": 20 }
browser_network_requests NET

列出捕获的 HTTP 请求（方法 / 状态 / 类型 / 大小 / 耗时 / URL），支持按状态、方法与 URL 过滤。

{ "statusMin": 400, "limit": 50 }
browser_network_detail NET

单个请求的完整请求 / 响应头、状态、大小、耗时；body: true 附带响应体。默认脱敏。

{ "requestId": "1234.5", "body": true }
browser_har NET

导出 HAR 1.2（不含响应体），可导入 DevTools / Fiddler 人工分析。凭据默认脱敏。

{ "path": "C:\\Users\\me\\capture.har" }
browser_mock_requests NET

按 URL 子串 + 方法拦截请求，返回假状态 / 头 / 体；action: continue 只观察并放行。

{ "urlContains": "/api/v1/quote", "status": 200, "body": "{\"price\":42}" }
browser_list_mocks NET

列出当前 mock 规则：匹配器、状态、命中次数。

{ }
browser_clear_mocks NET

按 id 删除单条 mock 规则，或清空全部并停止拦截。

{ "id": "rule-1" }
browser_performance DIAG

页面性能摘要：导航耗时（TTFB / DOMContentLoaded / load）、首绘、资源体积与慢资源、JS 堆、DOM 规模。只读诊断。

{ "slowest": 5 }
browser_resize DIAG

调整视口尺寸，用于响应式测试；随后重新快照即可看到适配后的结构。

{ "width": 390, "height": 844 }
browser_tabs DIAG

标签页列表 / 新建 / 切换 / 关闭。它也是接入验证的标准调用：能返回标签列表才算接通。

{ "action": "list" }
